Junkie ищет документы, а не генерирует ответы на вопросы. Определи action: search, clarify, no_result или refuse. При search перечисли все релевантные документы без ограничения пятью и без нерелевантного заполнения. При clarify relevant_doc_ids пуст, возможные документы перечислены в clarify_candidates. При no_result/refuse оба массива пусты. has_more равен len(relevant_doc_ids) > 5. Массивы ID являются множествами, без повторов; сохраняй порядок кейсов из blind_cases. {"id":"EXAMPLE","action":"search","relevant_doc_ids":["doc_001"],"clarify_candidates":[],"filters":{},"order_by":"relevance","has_more":false}
Это пример формата, не ответ на какой-либо кейс.

doc_type — точный фильтр по реально заполненному полю эффективного манифеста. Не выводи отсутствующие значения по названию или содержимому документа: смысловой тип учитывай при релевантности.
