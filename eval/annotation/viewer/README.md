# Junkie annotation viewer

Минималистичный локальный viewer для ручной проверки предварительной агентной разметки.
Внешние сервисы, библиотеки и сеть для сборки не используются. Требуются Python 3 и уже установленный `pdftotext`.

Из корня репозитория:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 eval/annotation/viewer/build.py
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8765/eval/annotation/viewer/>. Также можно открыть `index.html` непосредственно в браузере после сборки.

- Свайпы и стрелки переключают кейсы. На компьютере также работают колесо мыши и трекпад; вертикальная прокрутка переключает кейс на границе прокрутки содержимого.
- `1` — верно, `2` — ошибка, `3` — не уверен. Повторное нажатие снимает оценку. Автоматического перехода после оценки нет.
- Нажатие на документ открывает извлечённый текст с поиском и ссылкой на оригинал. DOCX, PPTX и HTML скачиваются.
- «Все документы кейса» позволяет найти пропущенный документ. Доступный список учитывает владельца, searchable и fixture текущего кейса.
- «Предложить правку» сохраняет отдельное предложение по действию, документам, фильтрам и порядку. Исходная предварительная разметка не меняется.
- Оценки, заметки и предложения сохраняются в localStorage конкретного браузера и адреса страницы. Экспортируйте JSONL перед сменой браузера или адреса.
- Экспорт содержит 30 записей с verdict, note, proposed_annotation, original_annotation, updated_at и dataset_fingerprint. Непроверенные записи имеют verdict `unreviewed`.

`build.py` читает только blind_cases, preannotation, manifest, environment и доступные документы corpus/fixtures. Он проверяет SHA-256 и применяет fixtures до фильтрации доступа. Сгенерированный `data.js` игнорируется Git; оригиналы документов не копируются. Viewer не выполняет инструкции из документов.

Экспорт завершённой проверки сохранён в `../reviews/user_review_2026-10-27.jsonl`. Это результат проверки общей агентной подсказки одним человеком; он не является независимой A/B-разметкой или согласованным gold. Сборщик не читает и не использует оценки для изменения предварительной разметки.
