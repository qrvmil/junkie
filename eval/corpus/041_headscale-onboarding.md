# Подключение к VPN лаборатории (Headscale)

На компьютере используется приложение **Tailscale**, сервер лаборатории —
`https://vpn.example.invalid`. Вход выполняется через наш GitLab.

## 1. Подготовьте аккаунт

1. Зарегистрируйтесь или войдите в [GitLab лаборатории](https://gitlab.example.invalid).
2. Подтвердите адрес электронной почты.
3. Сообщите администратору свой GitLab username и попросите добавить вас в группу
   `access/example-group`. Одна регистрация в GitLab ещё не даёт доступа к VPN.

## 2. Установите Tailscale и подключитесь

Скачайте [Tailscale для своей ОС](https://tailscale.com/download), установите
и запустите его. Разрешите создание VPN-подключения, если система попросит.
Затем выполните шаги для своей ОС.

**Linux** — откройте терминал:

```bash
sudo tailscale up --login-server=https://vpn.example.invalid
```

**Windows** — откройте PowerShell от имени администратора:

```powershell
tailscale login --login-server=https://vpn.example.invalid
```

Если команда не найдена, закройте и снова откройте PowerShell после установки.

**macOS** — удерживая **Option (⌥)**, нажмите значок Tailscale в строке меню.
Откройте **Debug → Custom Login Server → Add Account…**, укажите
`https://vpn.example.invalid` и нажмите **Add Account**.

## 3. Завершите вход

Откройте ссылку, которую покажет команда, если браузер не открылся автоматически.
В браузере войдите в **GitLab лаборатории** и подтвердите авторизацию приложения.
Дождитесь сообщения об успешном подключении. В приложении Tailscale должно
появиться состояние **Connected**.

## 4. Проверьте подключение

В приложении Tailscale найдите VPN-адрес компьютера. Если используете командную
строку, выполните:

```text
tailscale ip -4
tailscale status
```

Первая команда должна показать адрес вида `100.x.x.x`, вторая — состояние
подключения и доступные устройства. Для работы с ресурсами лаборатории
оставляйте Tailscale включённым. На каждом новом компьютере повторите подключение.

## 5. Добавьте SSH-ключ для работы с GitLab и машинами

Для входа в VPN достаточно GitLab-аккаунта. SSH-ключ понадобится для
clone/push по SSH и входа на лабораторные машины.

Если ключа ещё нет, выполните в терминале или PowerShell:

```text
ssh-keygen -t ed25519 -C "work-laptop"
```

Примите предложенный путь и задайте пароль ключа. Если файл уже существует,
не перезаписывайте его: используйте существующий ключ или выберите другое имя.
Откройте файл `~/.ssh/id_ed25519.pub` (Windows:
`%USERPROFILE%\.ssh\id_ed25519.pub`) и скопируйте всю строку.
Приватный файл без `.pub` оставьте только на своём компьютере.

Откройте [SSH-ключи в GitLab](https://gitlab.example.invalid/-/user_settings/ssh_keys),
нажмите **Add new key**, вставьте строку в **Key**, задайте название компьютера
и выберите **Authentication** или **Authentication & Signing**. Сохраните ключ.

Проверьте доступ к GitLab:

```text
ssh -T -p ${GITLAB_SSH_PORT} git@gitlab.example.invalid
```

При первом подключении сверьте отпечаток ключа сервера с
[данными GitLab](https://gitlab.example.invalid/help/instance_configuration#ssh-host-keys-fingerprints).
Ожидаемый ответ — приветствие `Welcome to GitLab` с вашим username.

Для входа на лабораторную машину уточните у администратора её VPN-адрес
и своё Linux-имя пользователя. На машинах с настроенной синхронизацией
ключи из GitLab обновляются с периодичностью, указанной администратором; доступ определяется разрешённой
для этой машины GitLab-группой. Само подключение к VPN ещё не выдаёт SSH-доступ.
После подтверждения доступа подключайтесь с включённым VPN:

```text
ssh LINUX_USER@VPN_ADDRESS
```

Замените `LINUX_USER` и `VPN_ADDRESS` данными администратора; при первом входе
сверьте с ним отпечаток ключа машины. SSH на машине использует порт 22,
а SSH для репозиториев GitLab — ${GITLAB_SSH_PORT}.

## Если не получилось

- **Отказ во входе:** проверьте, что вошли в нужный GitLab-аккаунт, подтвердили
  почту и администратор добавил вас в `access/example-group`.
- **Предлагается вход через Google или Microsoft:** повторите подключение
  с адресом сервера `https://vpn.example.invalid` из шага 2.
- **VPN подключён, но ресурс недоступен:** отправьте администратору свой GitLab
  username, ОС, имя компьютера и текст ошибки.

Инструкции клиента: [Windows](https://docs.headscale.org/usage/connect/windows/),
[macOS](https://docs.headscale.org/usage/connect/apple/),
[SSH-ключи GitLab](https://docs.gitlab.com/user/ssh/).
