# КТ-3: карта сдачи и доказательств

Требования сверены с [актуальным `project.md` курса](https://github.com/xufana/llm-system-engineering/blob/main/project.md).
Числовое сравнение использует B0/B1 из `full-01` и Junkie из `full-02` на
одном открытом dev-наборе. Исходный Junkie из `full-01` сохранён для парного
сравнения. Это не оценка на закрытом holdout и не новый запуск после правок
`kt3/review-fixes`.

## Границы результата

- `full-02` отличается от `full-01` алгоритмом поиска и промптом; вклад каждого
  изменения по отдельности не измерялся. B0/B1 не перезапускались.
- На `full-02` полезны 3/6 уточнений; S01/S02 не проходят; E84/E116
  регрессировали; P95 поиска 6,83 с выше цели.
- `ParsedQuery` Junkie остаётся диагностическим `pending` для E26: разбор
  запроса не был записан. Семантические показатели метаданных завершены.
- H0 описан как человеческая альтернатива в дизайн-доке, но не включён в
  измеренное сравнение. Текущий индекс живёт в памяти, а `saved://` открывается
  только внутри локального архива. Шесть PNG не проходят OCR.
